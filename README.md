# טניס פיקסל 🎾

משחק טניס יחידים בפיקסל ארט, בהשראת הגיים בוי של שנות ה-80. רץ בדפדפן במחשב ובנייד, בלי התקנה ובלי שרת: פשוט פותחים את `index.html`.

## שחקנים
| שחקן | רמה | משפטים |
|---|---|---|
| **טל** – המאמנת | הכי גבוהה | "יותר מהאגן" · "תבוא/י לכדור מלמטה" · "היית מגיע/ה לזה" (בנקבה מול ליאור) |
| **ציון** | טוב בינוני | ניצחון: "ממש אלקרז" · "חייבת לי קפה" / הפסד: "איזה אפס" · "אייי קרעתי את הברך" |
| **ליאור** (עם מצחייה) | בינונית | ניצחון: "מי זאת?!" · "ראית איך רצתי לכדור??" / הפסד: "סעמק" · "אמאשך" · "המחבט שבור היום" |

## מצבי משחק
- **אימון מול טל**: טל מזינה כדורים וכל כדור שנוחת אצלה נספר ברצף. ציון יכול להגיע עד 123 וליאור עד 100.
- **משחק אמיתי**: עד 3 משחקונים, עם ספירת טניס רגילה (15/30/40, שוויון ויתרון). טל תמיד מנצחת, וליאור תמיד מנצחת את ציון.

## שליטה
- **נייד**: מחזיקים את האצבע על המגרש וגוררים, והשחקן רץ אליה. נגיעה במסך מגישה.
- **מחשב**: גוררים עם העכבר או זזים עם החצים או WASD. רווח מגיש, Esc עוצר.
- המכה אוטומטית ברגע שהכדור מגיע לשחקן. במקלדת אפשר לכוון עם החצים ברגע המכה.
